# 🌾 AI AgriConnect – Direct Farmer-to-Buyer Marketplace

Full-stack college/demo project.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB + Mongoose
- Auth: JWT + bcrypt
- Payment: Demo payment (safe for college testing)

## Run
1. Open two terminals.
2. Backend:
   cd backend
   npm install
   npm run dev
3. Frontend:
   cd frontend
   npm install
   npm run dev

Set MongoDB and JWT values in backend/.env using backend/.env.example.
